Six pieces. Six skills.

Each level teaches one idea and gives you one task. You move on when you can do it without hints.

  1. Pawn The first move

    Tell the assistant what you want and watch a page appear.

  2. Knight The unexpected jump

    Ask for a change. See why exact words get exact results.

  3. Bishop The long diagonal

    Write a short rulebook the assistant reads before every game.

  4. Rook The straight line

    Say yes, say no, and take back a move.

  5. Queen Full power

    Ask for a plan first. Change it. Then approve it.

  6. King Checkmate

    Direct a small page from blank to done, with no hints.

Questions

What is Claude Code?

Claude Code is a tool made by Anthropic. You tell it what you want in plain words, and it writes the code for you.

This game is not Claude Code. It is a safe place to practice how to work with it.

Is it free?

The game is free and has no sign-up.

The real Claude Code is a paid product. Anthropic’s website lists what you need to use it.

Do I need to know how to code?

No. The game starts from zero. Every new word is explained at the moment you need it.

What do I need to play?

A phone, a tablet or a computer with a web browser.

Later, for the first real session this game prepares you for, you will need a computer.

Does a real AI answer me here?

No. Every answer in this game is written in advance. That keeps the game free, private and the same for everyone.

What do you store about me?

Nothing about you. The game saves which steps you have finished, and only inside your own browser. Nothing is sent anywhere.

You can erase it at any time with “Reset progress” on the level map.
